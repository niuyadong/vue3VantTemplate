# 后端工程设计方案

## 1. 技术选型

### 核心框架
- **Node.js** + **Express**：轻量级高性能框架，适合构建 RESTful API
- **TypeScript**：提供类型安全，与前端保持一致的开发体验
- **MongoDB**：NoSQL 数据库，灵活存储复杂数据结构

### 关键依赖
- **jsonwebtoken**：JWT Token 认证
- **bcrypt**：密码加密
- **multer**：文件上传处理
- **cors**：跨域支持
- **helmet**：安全头部配置
- **winston**：日志管理
- **express-validator**：请求参数验证

## 2. 项目结构

```
backend/

├── package.json          # 项目配置

```

## 3. 数据库设计

### 用户表 (users)
- `_id`: ObjectId
- `username`: String (唯一)
- `password`: String (加密)
- `email`: String (唯一)
- `avatar`: String
- `roles`: Array<String>
- `permissions`: Array<String>
- `createdAt`: Date
- `updatedAt`: Date

### 商品表 (products)
- `_id`: ObjectId
- `name`: String
- `description`: String
- `price`: Number
- `stock`: Number
- `categoryId`: ObjectId (关联分类)
- `images`: Array<String>
- `status`: String (active/inactive)
- `createdAt`: Date
- `updatedAt`: Date

### 商品分类表 (categories)
- `_id`: ObjectId
- `name`: String
- `parentId`: ObjectId (可选)
- `sort`: Number
- `createdAt`: Date

### 订单表 (orders)
- `_id`: ObjectId
- `orderNo`: String (唯一)
- `userId`: ObjectId (关联用户)
- `totalPrice`: Number
- `status`: String (pending/payment/shipped/delivered/cancelled/refunded)
- `paymentMethod`: String
- `address`: Object
- `items`: Array<Object> (商品详情)
- `createdAt`: Date
- `updatedAt`: Date

### 活动表 (activities)
- `_id`: ObjectId
- `title`: String
- `description`: String
- `startTime`: Date
- `endTime`: Date
- `location`: String
- `image`: String
- `status`: String (upcoming/ongoing/ended)
- `createdAt`: Date

### 活动报名表 (activity_enrollments)
- `_id`: ObjectId
- `activityId`: ObjectId (关联活动)
- `userId`: ObjectId (关联用户)
- `status`: String (joined/cancelled)
- `createdAt`: Date

## 4. API 接口实现

### 用户模块
- `POST /api/user/login` - 登录
- `GET /api/user/info` - 获取用户信息
- `POST /api/user/logout` - 登出
- `PUT /api/user/info` - 更新用户信息
- `POST /api/user/password` - 修改密码
- `POST /api/user/refresh-token` - 刷新Token

### 商品模块
- `GET /api/product/list` - 获取商品列表
- `GET /api/product/:id` - 获取商品详情
- `GET /api/product/categories` - 获取商品分类
- `GET /api/product/hot` - 获取热门商品
- `GET /api/product/recommend` - 获取推荐商品
- `GET /api/product/search` - 搜索商品
- `POST /api/product` - 添加商品
- `PUT /api/product/:id` - 更新商品
- `DELETE /api/product/:id` - 删除商品

### 订单模块
- `GET /api/order/list` - 获取订单列表
- `GET /api/order/:id` - 获取订单详情
- `POST /api/order` - 创建订单
- `POST /api/order/:id/pay` - 支付订单
- `POST /api/order/:id/cancel` - 取消订单
- `POST /api/order/:id/confirm` - 确认收货
- `POST /api/order/:id/refund` - 申请退款
- `GET /api/order/statistics` - 获取订单统计

### 活动模块
- `GET /api/activity/list` - 获取活动列表
- `GET /api/activity/detail/:id` - 获取活动详情
- `POST /api/activity/join` - 报名参加活动
- `GET /api/activity/my-activities` - 获取我参加的活动列表
- `POST /api/activity/cancel/:id` - 取消报名

### 环境配置

### 集成方案
